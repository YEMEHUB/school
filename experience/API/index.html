선생님용 안내 · 실제 데이터 연결

실제 중계 API를 사용하므로 인터넷 연결이 필요합니다. 인증키는 중계 서버에서 자동 처리합니다. 연결 실패 시 인터넷 연결과 서버 상태를 확인하세요. 브라우저의 CORS 차단은 학생 입력 문제가 아니며, 선생님이 중계 서버의 허용 설정을 확인해야 합니다.
