학생이 입력할 값은 음식 이름 하나!

출력명세의 자료형은 모두 문자열입니다. 영양정보는 기준량에 해당하며, 실제 데이터에서 값이 비어 있으면 ‘정보 없음’으로 표시합니다.

03음식명 검색 테스트 · 미리보기

이름을 보내고, 결과를 확인해 보세요.학습용 가상 데이터 · 실제 조회 아님

‘김밥’ 또는 이름의 일부인 ‘김’을 입력해 보세요. 이 파일에는 김밥 예시 1개만 준비되어 있습니다.

보내는 정보   FOOD_NM_KR=김밥 & type=json

이용안내
1. 요청과 응답 살펴보기입력한 음식 이름이 요청변수에 어떻게 들어가는지, 결과가 JSON으로 어떻게 표현되는지 확인하세요.
2. 내 웹앱에 추가하기제작 프롬프트를 복사해 음식 검색과 식단 추가·삭제, 영양소 합계 기능을 만들어 보세요.
3. 완성한 앱 확인하기검색·추가·삭제가 되는지 확인하고, 데이터의 출처와 가상 데이터 사용 여부를 표시하세요.
선생님용 안내 · 실제 데이터 연결
