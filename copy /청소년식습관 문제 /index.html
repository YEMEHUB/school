관련 자료 수집하기

팀에서 정한 주제의 버튼을 눌러 관련 자료를 찾아보세요.
정부기관 사이트(go.kr)의 PDF 자료를 검색합니다.

🔎 다른 키워드도 검색해 보세요!

위 버튼을 누르면 site:go.kr filetype:pdf 조건으로 구글 검색 결과가 새 탭에서 열립니다.
site:go.kr은 정부기관 홈페이지를, filetype:pdf는 PDF 문서를 찾는 검색 조건이에요.
원하는 주제가 없다면 아래에 키워드를 직접 입력해 보세요. 같은 조건이 자동으로 적용됩니다.

활동 방법 · STEP 1. 팀별로 키워드 하나 선택 → STEP 2. 팀원 각자 자료 수집 → STEP 3. 협의하여 사용할 자료 선별
